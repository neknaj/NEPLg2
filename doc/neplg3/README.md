# NEPLg3 ドキュメント

NEPLg3 は将来の次世代仕様候補であり、2026-05-24 時点では仕様も実装も未確定である。

現行開発の対象は NEPLg2 から NEPLg2.1 への表層構文移行である。NEPLg2.1 は `nepl-core/` と既存 `stdlib/` / `tests/` を更新する作業であり、このディレクトリの文書を現在の正仕様として扱ってはならない。

| ディレクトリ | 内容 |
|---|---|
| [spec/](./spec/index.md) | NEPLg3 の draft 言語仕様 |
| [impl/](./impl/index.md) | NEPLg3 の draft ブートストラップコンパイラ実装設計 |

現行実装（NEPLg2）と NEPLg2.1 移行の利用・保守ドキュメントは [../README.md](../README.md) と [../neplg2/neplg21_syntax_migration_plan.md](../neplg2/neplg21_syntax_migration_plan.md) を参照する。
