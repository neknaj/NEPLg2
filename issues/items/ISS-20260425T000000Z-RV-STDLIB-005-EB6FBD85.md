# RV-STDLIB-005: stdio read_all が 4096 byte で切り捨てる

旧 `doc/review20260425` から移行した Issue。新しい正の ID は `ISS-20260425T000000Z-RV-STDLIB-005-EB6FBD85`。

## 要約

`read_all` という名前にもかかわらず、text input を全て読みません。4096 byte を超える入力は正常系として切り捨てられます。

## 影響

競技プログラミングや CLI tool の標準入力で誤答になります。バグとして発見しづらく、入力サイズに依存します。

## 修正方針

`stdio_read_all_bytes` を基礎にし、EOF まで growable buffer で読みます。固定長 helper が必要なら `read_chunk` など別名にします。

## 対応結果

`read_all` を 4096 byte 固定の単発 `fd_read` から、EOF まで反復する growable buffer 実装へ変更した。
4096 byte から開始し、buffer が埋まるたびに 2 倍へ `realloc` する。
`fd_read` が 0 byte を返した時点で、先頭 4 byte に実読み込み長を書き戻して `str` として返す。

`std/streamio.nepl` の注意書きも、text stdin が 4096 byte 固定ではなく `std/stdio.read_all` に従って EOF まで読む内容へ更新した。
`tests/stdlib/stdio_read_all.n.md` に 4128 byte の stdin を与える回帰テストを追加し、`load_i32 read_all` が入力全体の byte 数と一致することを固定した。

## 検証

4097 byte 以上の stdin を与え、`len read_all` が入力 byte 数と一致するテストを追加します。

- `node nodesrc/tests.js -i tests/stdlib/stdio_read_all.n.md --no-tree -o tmp/stdio-read-all.json -j 1`: 1/1 passed
- `node nodesrc/tests.js -i tests/stdlib/stdio_read_all.n.md -i tests/stdlib/io.n.md -i tests/stdlib/streamio.n.md --no-tree -o tmp/stdio-read-all-suite.json -j 1`: 20/20 passed
