# RV-STDLIB-006: fs/cliarg の主要テストが skip されている

旧 `doc/review20260425` から移行した Issue。新しい正の ID は `ISS-20260425T000000Z-RV-STDLIB-006-673F4E12`。

## 要約

filesystem と argv は runtime 依存が強いにもかかわらず、回帰テストが skip されています。CLI runtime と stdlib wrapper のズレを検出できません。

## 影響

path_open、args_get、fd_read の ABI 不一致や buffer size バグが残りやすくなります。

## 修正方針

test runner に fixture file と argv/stdin 指定を持たせ、fs/cliarg の最小成功・失敗ケースを実行可能にします。skip は runtime 未対応のケースだけに限定します。

## 検証

`fs_read_to_string` で fixture file を読む test、`cliarg_count` / `cliarg_get` の argv test を追加します。

## 対応

- `stdlib/std/fs.nepl` の 5 件の skipped doctest を実行可能な fixture に置き換えた。
- `stdlib/std/env/cliarg.nepl` の 5 件の skipped doctest を実行可能な C string / argv fixture に置き換えた。
- 実行可能化で露出した `fs_open_read` の read rights 不足を修正し、WASI `path_open` で `FD_READ` right を要求するようにした。
- `tests/stdlib/fixtures/fs_read_sample.txt` を追加し、host filesystem preopen 経由の read 成功経路を固定した。
