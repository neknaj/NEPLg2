# RV-STDLIB-022: HashMap doctest にインデント不整合が残っている

旧 `doc/review20260425` から移行した Issue。新しい正の ID は `ISS-20260425T000000Z-RV-STDLIB-022-65715E0B`。

## 要約

hashmap の public doctest が、現行 parser の indent 幅ルールに合っていません。これは runtime 以前の fixture 品質問題で、HashMap API の実行時問題と混ざると原因調査を誤ります。

## 影響

旧レビュー本文を参照。

## 修正方針

該当 doctest の生成ソースを抽出し、`#indent` と本文 indent の不一致だけを直します。API の意味や検証内容は変えず、parser が受理する形に揃えます。

## 対応結果

`get` の doctest で `if` の続きに置いた `match` block の indent を `#indent 4` に合わせました。
indent 修正後に露出した by-value `get` の所有権問題も、missing check 用の空 map と existing value check 用の map を分けて解消しました。
