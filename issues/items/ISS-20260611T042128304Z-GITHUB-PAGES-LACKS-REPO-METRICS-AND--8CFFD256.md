# ISS-20260611T042128304Z-GITHUB-PAGES-LACKS-REPO-METRICS-AND--8CFFD256: GitHub Pages lacks repo metrics and current CI result viewers

## 概要

GitHub Pages exposes outdated manual test viewers and no metrics.html page. The current CI writes doctest JSON under dist/tests, but tests.html still defaults to ./tests.json and testinfo.html expects a cargo-test.log that CI no longer publishes.

## 対象

- `web/tests.html, web/testinfo.html, web/index.html, repo_metrics.ts, .github/workflows/ci.yml`

## 根拠

- `repo_metrics.ts` は JSON / CSV 出力を持つが、CI workflow から Pages artifact へ生成されていなかった。
- `web/index.html` は `tests.html` / `testinfo.html` を Trunk copy-file にしていたが、`metrics.html` は存在せず copy 対象でもなかった。
- `web/tests.html` は旧 `./tests.json` を default にしており、現行 CI の `dist/tests/tests-current.json`、`nmd-tests.json`、`examples-tests.json` などを読まなかった。
- `web/testinfo.html` は `./tests/cargo-test.log` を期待していたが、現行 CI は cargo log を Pages artifact に publish していない。
- ローカル Trunk build は `web/dist` に playground root を出力するため、workflow が `dist` だけを upload すると root の viewer HTML が final Pages artifact へ入らない可能性があった。

## 問題

GitHub Pages exposes outdated manual test viewers and no metrics.html page. The current CI writes doctest JSON under dist/tests, but tests.html still defaults to ./tests.json and testinfo.html expects a cargo-test.log that CI no longer publishes.

## 影響

https://neknaj.github.io/NEPLg2/metrics.html is unavailable, and tests.html/testinfo.html do not reliably show the current CI results generated by the workflow.

## 修正方針

Generate repo_metrics.ts JSON/CSV into the Pages artifact, copy metrics.html through Trunk, and update test viewers to load the current dist/tests artifacts/status.json by default.

## 検証

- `node nodesrc/test_pages_ci_metrics_contract.js`
- `node nodesrc/run_repo_metrics.js --root . --json tmp/pages-metrics-repo.json --csv tmp/pages-metrics-repo.csv`
- `NEPL_REPO_METRICS_FORCE_TSC=1 node nodesrc/run_repo_metrics.js --root . --json tmp/pages-metrics-repo-tsc.json --csv tmp/pages-metrics-repo-tsc.csv`
- `trunk build`
- `node nodesrc/cli.js -i tests/playground_editor --playground-editor-tests -o json=tmp/pages-metrics-playground-editor.json` (`caseCount=13`, `passedCount=13`, `failedCount=0`)
- inline HTML script parse for `web/tests.html`, `web/testinfo.html`, `web/metrics.html`
- simulated CI copy artifact check for root `dist/metrics.html`, `dist/tests.html`, `dist/testinfo.html`, and `dist/metrics/repo_metrics.json`
- `node nodesrc/issues.js index --dir issues`
- `node nodesrc/issues.js check --dir issues`
- `node nodesrc/run_source_policy_regressions.js --warn-only`
- `git diff --check`

## 解決

- `nodesrc/run_repo_metrics.js` を追加し、`repo_metrics.ts` を metrics authority として維持したまま CI から JSON / CSV を生成できるようにした。Node が TypeScript strip 実行を持たない場合は repo の TypeScript toolchain で compile してから実行する。
- `.github/workflows/ci.yml` は Trunk の `web/dist` を Pages artifact root の `dist/` に同期し、`dist/metrics/repo_metrics.json` と `dist/metrics/repo_metrics.csv` を生成する。
- pending / final の `dist/tests/status.json` に `run_url`、`head_sha`、`generated_at` を追加し、Pages 側から対象 CI run を辿れるようにした。
- `web/metrics.html` を追加し、`repo_metrics.ts` の JSON と CSV を Pages root から確認できるようにした。
- `web/tests.html` は現行 CI の `./tests/status.json` と doctest JSON 群を読む詳細 viewer に置き換えた。
- `web/testinfo.html` は未公開 cargo log viewer ではなく、現行 CI job status と published test JSON inventory を表示する page に置き換えた。
- `nodesrc/test_pages_ci_metrics_contract.js` を追加し、Pages root HTML、metrics artifact、CI status JSON、現行 test artifact 名の契約を source policy として固定した。
